# Python para Data Science (Primeiros Passos) — Alura

Notebook de estudos desenvolvido durante o curso **"Python para Data Science: Primeiros passos"**, da [Alura](https://www.alura.com.br/). O projeto reúne os principais fundamentos da linguagem Python aplicados a cenários simples de análise de dados, como cadastros escolares e cálculo de médias.

## 🎯 Objetivo

Consolidar os conceitos básicos de Python necessários para quem está iniciando na área de Data Science, através de exercícios práticos propostos ao longo do curso.

## 🧠 Conteúdos abordados

- **Introdução ao Python e Google Colaboratory**: ambiente de desenvolvimento e primeiros comandos (`print()`)
- **Variáveis e tipos de dados**: inteiros, floats, strings e booleanos
- **Manipulação de strings**: métodos como `upper()`, `lower()`, `strip()` e `replace()`
- **Entrada de dados**: uso de `input()` e conversão de tipos (`int()`, `float()`, `str()`, `bool()`)
- **Estruturas condicionais**: `if`, `elif`, `else` e operadores lógicos (`and`, `or`, `not`, `in`)
- **Estruturas de repetição**: laços `while` e `for`, uso da função `range()`
- **Estruturas de dados**: listas (indexação, fatiamento/slicing, `append()`, `extend()`, `remove()`) e dicionários (`pop()`, `keys()`, `values()`, `items()`)

## 🛠️ Tecnologias utilizadas

- Python 3
- Google Colaboratory / Jupyter Notebook
